# 4. Initial RTM Contribution — Source/Stakeholder → Requirement

This table forms the stakeholder-to-requirement half of the team's Initial Requirements Traceability Matrix (RTM). It will be joined with Person 2's NFR/constraint half during the team RTM assembly session, and extended with Design/Architecture, Issue/PR, Implementation and Test columns as the project progresses through later milestones.

| Source / Stakeholder | Requirement | Acceptance Criterion |
|---|---|---|
| Requester | **FR-001 — Submit request** | Request is successfully created with a unique record. |
| Requester | **FR-002 — View status** | Current, controlled request status is displayed. |
| Staff | **FR-003 — View relevant requests** | Authorised staff can access relevant requests. |
| Staff | **FR-004 — Assign responsibility** | Responsible staff member is recorded. |
| Staff | **FR-005 — Update status** | Valid, controlled status change is saved. |
| Staff | **FR-006 — Record actions/comments** | Information is stored against the request. |
| Management | **FR-007 — Monitor request status** | Open/overdue/resolved/closed requests can be identified. |
